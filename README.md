# Dispenser-arduino

Projeto com ESP32 para lembrete de medicamentos, utilizando RTC DS1307, display LCD I2C, teclado matricial 4x4 e LED.

### Funcionalidades
- Exibição de data e hora.
- Programação de horário pelo teclado.
- Alerta visual por LED durante 30 segundos.

### Bibliotecas
- RTClib
- LiquidCrystal_I2C
- Keypad
